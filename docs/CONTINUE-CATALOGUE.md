## Где лежат исправления и как их продолжать

- `data/catalogue.json` — точные UUID, источники, проверенные поля и допустимые
  прежние значения. `scripts/catalogue*.js` — проекция компендиумов, миграция
  и функциональные правила; интеграция проходит через общие обработчики Addenda.
- Сохранять UUID, ID эффектов и пользовательские изменения. Не заменять
  количество боеприпасов персонажа количеством в упаковке. Не редактировать
  LevelDB как текст. Не вводить сопоставление авторских предметов по похожим
  названиям. Название эффекта употребления и `system.consumed` меняются вместе.
- После каждого исправленного предмета обновлять
  `catalogue-coverage-2026-09-14.json`, список оставшихся записей и отчёт.
  Не повышать статус только за перевод подписи эффекта.
- Проверки логики: `node tools/selftest-catalogue.mjs`,
  `node tools/selftest-install.mjs`, `node tools/selftest-area.mjs`,
  `node tools/selftest-pkt.mjs`.
