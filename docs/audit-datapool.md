# Сверка материала Data Pool с содержимым Foundry

Дата сверки: 2026-08-23. Источник: четыре выгрузки Data Pool (версия 1.6.4) —
«Оружейный Магазин», «Броня», «Предметы», «Техапгрейды».

Сверялось с индексом из **55 Item-компендиумов** (система `cyberpunk-red-core`
v0.92.4 + все установленные модули), **1463 предмета**, из них 1117 с русскими
названиями и 1030 с русскими описаниями из Babele.

Проверка шла в три прохода: по названию, по тексту описания (вес редких общих
слов) и точечно по английским терминам корбука — потому что фанатский перевод
Data Pool и перевод компендиума расходятся почти всегда. Например
«Увеличенный Магазин» — это Extended Magazine, а «Коннектор Смартлинк» —
Smartgun Link; ни одну из этих пар сравнение названий не находит.

## Что стоит уточнить

Три позиции я засчитал как имеющиеся, но соответствие не буквальное — стоит
глянуть глазами и решить:

- **Маска-противогаз** → в системе Anti-Smog Breathing Mask («Респиратор»).
  Респиратор от смога и противогаз — не одно и то же.
- **Очки для Брейнданса** → нашёлся Braindance Recorder, но это кибернетика,
  а не носимый гаджет.
- **Умные уши** → похоже на Amplified Hearing (кибераудио), но в Data Pool это
  может быть отдельным предметом снаряжения.

## Что добавлено в модуль

Все 60 недостающих позиций перенесены в компендиумы — **63 предмета**
(комплекты брони «тело + голова» разведены на отдельные предметы, как это
сделано у всей штатной брони системы).

| Пак | Предметов | Что внутри |
|---|---:|---|
| Addenda: Модификации | 27 | 11 модификаций оружия + 16 техапгрейдов |
| Addenda: Снаряжение | 28 | 26 предметов + 2 техапгрейда, не ложащихся в механику модификаций |
| Addenda: Броня и одежда | 8 | 5 позиций, из них три комплекта «тело + голова» |

Названия и описания перенесены из документов дословно. Заполнены только те
поля, которые документ задаёт прямо: цена, ОС и штраф брони, размер в слотах,
типы оружия, на которые модификация ставится. Игромеханические бонусы нигде не
додуманы.

**Что из документов система выразить не может** — осталось текстом в описании:

- замена режима огня (Автоспуск пистолета, Узел автоматического управления
  огнём, Внутренний циклический механизм ПП) — у модификаций нет поля для
  режимов стрельбы;
- «урон +1d6» (Усиленная тетива, Перекалибровка снайперской винтовки) —
  модификатор урона у системы числовой, а не в кубах;
- подмена таблицы дальности (Модификация таблицы дальности);
- выдача дополнительного слота под прицел (Рельса совместимости);
- раздельные штрафы брони по статам: у Тяжёлого и Гибридного Metalgear® в
  документе −4 РЕА и −5 ЛВК/СКО, а система применяет один штраф ко всем трём.
  Взято значение по РЕА, полная формулировка вынесена в описание.

**Два техапгрейда заведены обычными предметами**, а не модификациями:
«Экспериментальная Нагрузка» ставится на боеприпасы, «Супер Подкат» — на
программу, а такие типы предметов система улучшать не умеет вовсе.

## Проверка работоспособности

| Проверка | Объём | Результат |
|---|---:|---|
| Структура предметов (`validate-items.js`) | 63 предмета | без ошибок |
| Установка модификаций (`selftest-install.mjs`) | 447 проверок | без провалов |
| Логика ограничений (`selftest.mjs`) | 10 случаев | без провалов |
| Чтение собранных компендиумов | 63 записи | id уникальны, конфликтов с чужими компендиумами нет |

Проверка структуры сверяет каждый предмет с эталоном того же типа из
компендиумов системы и со справочниками допустимых значений, вычитанными из
`config.js`. Она уже поймала один реальный пропуск — отсутствовало поле
`critFailEffect`, из-за которого модификации могли уронить лист предмета.

Проверка установки берёт каждую из 27 модификаций и прогоняет через ту же
функцию, которую система вызывает при навешивании, против всех 18 типов оружия:
на разрешённых встаёт, на остальных отклоняется с сообщением.

Живой запуск в Foundry не выполнялся — сервер не поднимался.
