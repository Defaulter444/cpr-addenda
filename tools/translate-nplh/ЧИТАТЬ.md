# Перевод No Place Like Home

Модуль чужой и локализации не имеет вовсе: весь текст вшит в шаблон и скрипты.
Поэтому перевод — это правка его файлов, и **обновление модуля её сотрёт**.

Чтобы вернуть перевод после обновления, запустите по порядку:

```
python 01_template.py    # лист штаб-квартиры
python 02_rules.py       # названия улучшений и правила
python 03_scripts.py     # роли, подработка, диалоги, ошибки
python 04_tests.py       # проверки модуля — под переведённые сообщения
```

Затем убедитесь, что ничего не сломалось:

```
cd ../../../no-place-like-home
node --test tests/*.test.mjs
```

Должно быть 63 из 63.

## Что переводится, а что нет

Переводится только видимый текст. НЕ трогаются:

- идентификаторы улучшений (`evidence`, `garage`, `lockup`…) — по ним записаны
  покупки, переименование стёрло бы уже купленное;
- ключи ролей (`rockerboy`, `solo`…) и идентификаторы компендиума — по ним
  модуль находит роль персонажа;
- выражения `{{...}}` в шаблоне, `${...}` в строках, атрибуты `name=`, `data-*`
  и имена классов.

Скрипты проверяют это сами: если после замены изменилось число выражений,
полей или идентификаторов, они останавливаются и ничего не пишут.

## Почему правятся и проверки

Четырнадцать проверок модуля сверяли текст сообщений по-английски. Поведение они
проверяют то же самое — меняется только образец, с которым сравнивают.
